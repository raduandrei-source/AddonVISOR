AddonVisor

用户指南 · 版本 1.0.0 · Windows 10/11 · 已在 Blender 4.1 – 5.3 上测试
1概览

这是什么

新版 Blender 发布了，您装好之后却发现插件都不在了。只好一个个复制过去、逐个启用，等到真正要用时才发现哪些已经坏了。

AddonVisor 是一款小巧的 Windows 应用，能在 Blender 之外替您完成这些工作。它会找出您电脑上的所有 Blender，显示每个版本中使用了哪些插件，把它们迁移到您选择的版本，在做任何更改之前先在沙盒中测试，并准确告诉您哪里出了问题、原因是什么——有修复方法时还会一并提供。

设计理念

在 Blender 之外运行，因此能看到一切

Blender 内部的插件只能看到当前这一个版本。AddonVisor 独立运行，因此可以同时比较您所有的 Blender 版本——包括从未打开过的版本。

先测试，后更改

只有在目标版本设置的临时副本中运行成功后，才会真正安装。看到结果后，再由您决定安装哪些。

绝不改动原件

旧版 Blender 只会被读取。修复在副本上进行。每次真正安装都有备份，并可撤销。

点击次数少

它会自动扫描，自动选择最新的 Blender 作为目标版本，并为每个插件选取最新副本。大多数迁移只需点两下：先点一个快捷方式，再点安装并测试。

适用人群

适合拥有多个 Blender 版本和较多插件的用户；需要让团队迁移到新版本的工作室；想了解自己的插件在哪些版本中出问题的插件开发者。
不太适合只有一个 Blender、两三个插件的用户——Blender 自带的 Import previous settings 可能就够了。暂不支持 macOS 和 Linux。
2入门

安装

系统要求

  • Windows 10 或 11，64 位
  • Microsoft Edge WebView2 Runtime——Windows 11 已内置，Windows 10 通常也已安装
  • 已安装一个或多个 Blender 版本。已在 4.1 – 5.3 上测试；2.8x – 4.0 应该可以使用，但未经测试。
  • 仅在从 extensions.blender.org 下载和使用可选的 AI 助手时需要联网

安装程序

运行 AddonVisor-Setup-1.0.0.exe。无需管理员权限。AddonVisor 会出现在开始菜单和设置 → 应用中，可在那里卸载。

便携版

将 AddonVisor-1.0.0-portable.zip 解压到任意位置，然后运行 AddonVisor.exe。压缩包中还包含完整源代码。

Windows SmartScreen 首次运行时可能提示“Windows 已保护你的电脑”，因为这款应用较新，尚未进行代码签名。点击更多信息 → 仍要运行即可。只需操作一次。

首次启动

  1. AddonVisor 会自动扫描您的电脑：Program Files、Steam、Windows 注册表以及便携版 Blender 文件夹。每个 Blender 都会在后台隐藏启动，以读取其插件——这需要几秒钟。
  2. 随后您会看到矩阵。最新的 Blender 被选为目标版本。
  3. 用右上角的按钮切换语言：English、Français、Español、Deutsch、Русский、简体中文、日本語、Português (Brasil)、Română。帮助按钮会打开本指南。

读懂矩阵

符号含义
✓在该 Blender 版本中已启用且正常工作
○已安装，但未启用
✕已启用，但加载失败——将鼠标悬停可查看错误
!GPU 插件：无法在后台加载，已用小窗口重新测试
+已排队：将安装到目标版本中

最新副本列显示在您电脑上找到的该插件的最新版本，以及它来自哪个 Blender。名称下方的备注会提示：extensions.blender.org 上有更新的版本、某个版本已知会失败，或者您有已修补的副本。

3工作流程

1 · 选择目标版本

点击列标题，即可将该 Blender 设为目标版本。默认是已安装的最新版本——即使您从未打开过它。

2 · 勾选插件

  • 点击目标列中的空白格子，将该插件加入队列；再次点击即可移除。
  • 沿列按住并向下拖动，可一次勾选多个。
  • 或使用快捷方式：我的 5.1 + 5.2 配置 → 5.3（您最近两个版本中启用的所有插件）、所有可用插件 → 5.3 或清除。
  • 安装过但从未启用的插件隐藏在显示 N 个从未启用的插件下。

使用哪个副本

您无需选择来源版本。对于每个插件，AddonVisor 会查看您电脑上的所有副本，并按以下顺序选用：

  1. 您的已修补的副本（如果您修复过该插件，参见在副本上修复）；
  2. extensions.blender.org 上更新的兼容版本——当存在这样的版本，或已知您的本地副本会失败时。该行会显示“↑ extensions.blender.org 上有 11.0.12 · 将使用此版本”，并由 Blender 自行下载；
  3. 否则，使用声明支持目标版本的最新本地副本（blender_version_min/max 或 bl_info["blender"]）。

3 · 安装并测试

点击安装并测试（N）。

  1. 沙盒测试。目标版本的用户文件夹会被复制到一个临时文件夹，然后启动 Blender 并让它使用该副本。插件被复制进去后逐个启用。您真实的 Blender 文件夹不会有任何更改。GPU 插件会用小窗口重新测试——您可能会看到窗口一闪而过。
  2. 结果。您会看到哪些可用、哪些失败，并附有真实的 Python 错误。然后选择安装可用的 N 个、点击失败插件旁的修复，或点击取消。

撤销与备份

在真正安装之前，AddonVisor 会保存您的偏好设置以及将被替换的每个文件。

  • 在结果窗口中：↶ 撤销。
  • 之后：目标版本卡片中的↶ 撤销上次安装。

撤销会删除新增的内容，放回被替换的文件，并恢复您的偏好设置（如果该 Blender 之前没有偏好设置，则将其删除）。

4修复插件

在副本上修复

插件失败时，点击它旁边的修复。AddonVisor 会创建一个已修补的副本，并在其中应用您的修复——原件永远不会被编辑。

您提供的内容处理方式
diff 文件（.diff、.patch）按周围代码匹配；行号会被忽略，因此 AI 写的 diff 也能用
AI 聊天的完整回答（.md 或粘贴的文本）应用其中的每个 ```diff 代码块
完整的 .py 文件替换插件中同名的文件
修复后插件的 .zip替换整个副本

将文件拖到框中、点击框选择文件，或粘贴文本后点击应用粘贴的内容。来自任何 AI 的补丁都可以使用——Claude、ChatGPT、Gemini、Copilot。然后点击↻ 在沙盒中重新测试。如果内置助手的回答中包含 diff，点击应用 AI 补丁并重新测试即可一键完成。

安全规则

  • 要么全部应用，要么都不应用。如果补丁有任何部分不匹配，则不会写入任何内容，并会告诉您是哪个文件、哪一行。
  • 不会重复打补丁。已经应用过的补丁会被拒绝。
  • 缩进很重要。在 Python 中缩进会改变代码含义，因此必须匹配（Tab 与 4 个空格的差异可以容忍）。
补丁只保留在您的电脑上。对于付费插件，等待作者发布更新通常更稳妥——请把 %LOCALAPPDATA%\AddonVisor\logs\ 中的报告发给作者。

补丁列表

有补丁的行会显示 ▸。点击它可查看每个补丁：编号、文件名、修改了哪些文件以及修改时间。

  • ✕ 移除会撤销单个补丁：副本会从原件重建，其他补丁按顺序重新应用。如果后面的某个补丁依赖于它，则不做任何更改，并告诉您需要先移除哪一个。
  • ↺ 重置所有补丁——或备注旁的小 ↺——会删除已修补的副本，重新使用原件。

示例：Blender 5.3 中的 BlenderGIS

Blender 5.3 自带 Python 3.13，该版本移除了 imghdr 模块。BlenderGIS 2.2.10 在两个文件中使用了它，因此会报错 ModuleNotFoundError: No module named 'imghdr'。下面这个补丁在 imghdr 存在时继续使用它，否则改用一个简单的文件头检查：

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

下载完整补丁：BlenderGIS_2.2.10_python313_imghdr.diff——然后修复 → 拖入文件 → 重新测试。

5AI 助手

连接与使用

可选功能。测试失败后，它会读取错误报告，说明哪里出了问题以及如何修复，通常还会附上现成的 diff。不使用它，AddonVisor 的全部功能照常可用，且没有任何数据离开您的电脑。

Gemini——用 Google 账号获取免费密钥

  1. 点击使用 Google 继续，浏览器中会打开 Google AI Studio。
  2. 登录，点击 Create API key，复制密钥。
  3. 将其粘贴到 AddonVisor 中，然后点击连接。

Claude——付费 API 密钥

  1. 点击获取 Claude API 密钥，Claude Console 会打开。
  2. 在 Billing 中充值，在 API keys 中创建密钥（密钥只显示一次）。
  3. 粘贴密钥并点击连接。Claude Pro/Max 订阅不包含 API 用量；一次分析只需几美分。

本地 AI——在您的电脑上运行，免费

  1. 安装 Ollama（或 LM Studio、llama.cpp、Jan）并下载一个模型，例如 ollama pull gemma4:e4b。
  2. 在 AddonVisor 中选择本地，保留地址 http://localhost:11434/v1（LM Studio：http://localhost:1234/v1），然后点击查找模型。
  3. 选择一个模型并点击连接。

数据不会离开您的电脑。小模型速度快，但修复建议较弱——请务必在沙盒中重新测试；大模型（或 Claude / Gemini）更可靠。任何兼容 OpenAI 的服务器也可使用，包括需要 API 密钥的在线服务。

使用方法

  • 每次测试后自动读取日志（默认开启）：回答会显示在结果窗口中。
  • 或点击让 AI 分析这些错误。
  • 如果某个模型繁忙，AddonVisor 会等待并自动尝试其他模型；如果仍然失败，请点击↻ 重试。

发送给 AI 的内容

只发送失败插件的报告：Python 错误以及出错行附近约 17 行代码。包含您 Windows 用户名的路径会被替换为 %USERPROFILE%。密钥针对您的 Windows 用户加密存储（DPAPI）；点击断开即可将其删除。所用模型：Claude 为 claude-opus-5-5；Gemini 为您的密钥可用的最新 Flash 模型。 使用本地时，报告只发送到您电脑上的 AI 服务器。

6参考

文件与文件夹

所有内容都保存在 %LOCALAPPDATA%\AddonVisor\ 中，卸载时会保留，因此您的备份不会丢失。

文件夹 / 文件内容
backups\每次真正安装前的备份（供撤销使用）
logs\每次测试的 run_*.log 和 ai_report_*.md
patched\您修复过的插件副本，包含您应用的每个补丁
settings.json语言、AI 选项、额外的 Blender 文件夹
keys.jsonAI 密钥，针对您的 Windows 用户加密

隐私

  • 无需账号，无遥测，无数据分析。
  • 仅在访问 extensions.blender.org（查询有哪些扩展，以及通过 Blender 下载）和您连接的 AI 服务商时使用网络。
  • 其他一切都保留在您的电脑上。
  • 使用本地 AI（Ollama、LM Studio 等）时，报告永远不会离开您的电脑。

故障排除

问题解决方法
缺少某个 Blender 版本将其文件夹添加到 settings.json：{"extra_dirs": ["D:\\Apps\\blender-5.3"]}，然后点击重新扫描。不支持从 Microsoft Store 安装的版本。
测试期间有 Blender 窗口一闪而过正常现象：GPU 插件会用窗口重新测试。窗口会自动关闭。
“无法连接 AI：… high demand”服务商负载过高；其他模型也已尝试过。请稍后点击↻ 重试。
“hunk N does not match the file”该补丁是针对不同代码编写的（另一个版本，或副本已打过补丁）。打开 ▸，移除或重置补丁后再试。
“this patch is already applied”无需处理——该更改已在副本中。
“could not delete … a file is in use”关闭正在显示 patched\ 中文件的资源管理器窗口或编辑器，然后重试。
窗口一片空白安装或修复 Microsoft Edge WebView2 Runtime。
SmartScreen / 杀毒软件警告更多信息 → 仍要运行；如有需要，从隔离区恢复——并告诉我们，以便我们上报误报。

报告问题时，请附上 %LOCALAPPDATA%\AddonVisor\logs\ 中最新的 run_*.log，并列出您的 Blender 版本：GitHub Issues 或 gmcis.cutvisor@gmail.com。

常见问题

这是 Blender 插件吗？

不是——它是一款独立的 Windows 应用。正因如此，它才能同时看到您所有的 Blender 版本。

它会破坏我的 Blender 配置吗？

所有内容都会先在沙盒中测试；真正安装需要您确认，会先做备份，并且可以撤销。

它会自动修复插件吗？

如果 extensions.blender.org 上有更新的兼容版本，它会使用该版本；否则，您可以在副本上应用补丁（来自内置 AI 或其他任何 AI），然后重新测试。有些插件需要作者来修复。

它支持我购买的插件吗？

支持——它复制的是您电脑上已安装的内容，绝不会分享您的插件。

Mac / Linux？

暂不支持。

包含源代码吗？

包含。AddonVisor 采用 GNU GPL v3 许可；源代码就在下载包中。
