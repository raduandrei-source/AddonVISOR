AddonVisor

Guide de l’utilisateur · extension Blender · version 1.0.0 · Blender 4.2+ · Windows · Linux · macOS (non testé)
1Présentation

Qu’est-ce que c’est ?

Une nouvelle version de Blender sort, vous l’installez — et vos add-ons n’y sont pas. Vous les recopiez un par un, vous les activez, et vous ne découvrez ceux qui sont cassés qu’au moment où vous en avez besoin.

AddonVisor est une extension Blender qui fait tout cela pour vous. Installez-la dans votre Blender le plus récent, appuyez sur Open AddonVisor, et sa page s’ouvre dans votre navigateur web. Elle trouve toutes les versions de Blender de votre ordinateur — pas seulement celle dans laquelle vous êtes —, montre quels add-ons vous utilisez dans chacune, les déplace vers la version de votre choix, les teste dans un bac à sable avant de modifier quoi que ce soit, et vous dit précisément ce qui ne marche pas et pourquoi — avec une correction quand il en existe une.

N’importe quelle IA peut réparer ce qui casse — AddonVisor écrit le prompt pour vous. Quand un add-on échoue, appuyez sur Générer le prompt IA : vous obtenez une demande prête, avec le message d’erreur exact, le code qui échoue, les versions de Blender et de Python et le format de patch qu’AddonVisor comprend. Collez-la dans ChatGPT, Claude, Gemini, Copilot ou toute autre IA, recollez la réponse dans Réparer, et AddonVisor l’applique sur une copie puis lance Retester dans le bac à sable.

Philosophie

Dans Blender, mais il voit tous vos Blender

Un add-on ordinaire ne voit que le Blender dans lequel il tourne. AddonVisor lance vos autres versions de Blender en arrière-plan pour les lire : il peut donc toutes les comparer à la fois — y compris celles que vous n’avez jamais ouvertes.

Tester d’abord, modifier ensuite

Rien n’est réellement installé avant d’avoir fonctionné dans une copie jetable des paramètres de la cible. Vous décidez quoi installer après avoir vu le résultat.

Ne jamais toucher aux originaux

Les anciennes versions de Blender sont uniquement lues. Les corrections se font sur une copie. Chaque installation réelle a sa sauvegarde et peut être annulée.

Peu de clics

L’analyse se fait toute seule ; la version de Blender la plus récente est choisie comme cible, et la copie la plus récente de chaque add-on est retenue. La plupart des migrations tiennent en deux clics : un raccourci, puis Installer et tester.

Pour qui ?

Idéal pourToute personne ayant plusieurs versions de Blender et plus d’une poignée d’add-ons ; les studios qui font passer une équipe à une nouvelle version ; les développeurs d’add-ons qui veulent voir où leur add-on casse.
Moins adapté pourUne seule version de Blender avec deux ou trois add-ons — la fonction Import previous settings de Blender peut suffire. L’extension elle-même nécessite Blender 4.2 ou plus récent (les versions plus anciennes peuvent quand même servir de sources ou de cibles).
2Prise en main

Installation

Configuration requise

  • Blender 4.2 ou plus récent pour faire tourner l’extension — installez-la dans votre Blender le plus récent.
  • Windows 10/11 ou Linux (testés). macOS devrait fonctionner mais n’a pas encore été testé sur un Mac.
  • D’autres versions de Blender sur le même ordinateur, comme sources ou cibles. Testé avec 4.1 – 5.3.
  • Un navigateur web (celui par défaut est utilisé).
  • Internet uniquement pour les téléchargements depuis extensions.blender.org et pour l’assistant IA facultatif.

Installer

  1. Téléchargez addonvisor-1.0.0-extension.zip.
  2. Glissez-le dans la fenêtre de Blender, ou utilisez Edit › Preferences › Get Extensions › ⌄ › Install from Disk… et choisissez le fichier.
  3. Vérifiez qu’AddonVisor est coché dans Edit › Preferences › Add-ons.

Pour le supprimer : Edit › Preferences › Add-ons › AddonVisor › Uninstall.

Ouvrir AddonVisor

  1. Dans la Vue 3D, appuyez sur N et choisissez l’onglet AddonVisor (les mêmes boutons se trouvent dans les préférences de l’extension).
  2. Appuyez sur Open AddonVisor. Votre navigateur web par défaut ouvre la page AddonVisor.

La page ne fonctionne que sur cet ordinateur : son adresse est 127.0.0.1 et le lien contient une clé privée, si bien que d’autres ordinateurs et d’autres pages web ne peuvent pas l’utiliser. Tant qu’il tourne, le panneau affiche Running at 127.0.0.1:…, avec Copy Link (pour ouvrir la page dans un autre navigateur) et Stop AddonVisor.

Quand vous fermez Blender, ou appuyez sur Stop AddonVisor, la page affiche AddonVisor a été fermé. Rouvrez-le depuis Blender — un nouveau lien est créé à chaque fois.

Blender reste utilisable pendant qu’AddonVisor travaille : analyses, tests et téléchargements se font en arrière-plan.

Premier lancement

  1. À l’ouverture de la page, AddonVisor analyse votre ordinateur tout seul : Program Files, Steam, le registre Windows et les dossiers de Blender portables (sous Linux : dossiers Blender dans votre dossier personnel et /opt, Snap, Flatpak, Steam et le paquet de la distribution ; sous macOS : /Applications et ~/Applications). Chaque Blender est lancé de façon invisible en arrière-plan pour lire ses add-ons — cela prend quelques secondes.
  2. La matrice s’affiche. La version de Blender la plus récente est sélectionnée comme cible ; quand la cible est le Blender dans lequel vous êtes, le panneau de la cible l’indique.
  3. Changez de langue avec le bouton en haut à droite : English, Français, Español, Deutsch, Русский, 简体中文, 日本語, Português (Brasil), Română. Le bouton Aide ouvre ce guide.

Des notes sous le nom vous signalent qu’une version plus récente existe sur extensions.blender.org, qu’une version est connue pour échouer, ou que vous avez une copie corrigée.

3Mode d’emploi

1 · Choisir la cible

Cliquez sur l’en-tête d’une colonne pour faire de ce Blender la cible. Par défaut, c’est la version installée la plus récente — même si vous ne l’avez jamais ouverte.

Des add-ons pour le Blender où vous êtes

Le cas le plus fréquent : vous travaillez dans Blender 5.3 et voulez y retrouver les add-ons des versions précédentes. Quand la cible est le Blender dans lequel vous êtes, le panneau Version cible indique le Blender dans lequel vous êtes : les add-ons sont activés dans cette session.

  1. Appuyez sur Installer et tester. Chaque add-on est d’abord testé dans un Blender séparé, en arrière-plan, avec une copie de vos paramètres.
  2. Appuyez sur Installer les N qui fonctionnent. AddonVisor les teste encore une fois, copie dans votre Blender seulement ceux qui réussissent, les active dans cette session et laisse Blender enregistrer lui-même ses préférences. Ils sont utilisables tout de suite — sans redémarrage.
  3. Un add-on qui a échoué au test n’est jamais activé.

Annuler les désactive dans la même session, remet les fichiers en place et laisse Blender enregistrer de nouveau ses préférences.

Pourquoi ainsi : un Blender ouvert écrit ses préférences quand il se ferme, par-dessus toute modification faite de l’extérieur. Pour le Blender dans lequel vous êtes, AddonVisor ne modifie donc jamais lui-même le fichier de préférences — il demande à Blender de le faire.

Autres versions de Blender

N’importe quel autre Blender de l’ordinateur peut aussi être la cible, y compris des versions antérieures à 4.2. AddonVisor y installe les add-ons depuis l’extérieur, comme décrit dans Installer et tester. Ce Blender doit être fermé : s’il est ouvert, le panneau de la cible affiche ouvert en ce moment : fermez-le avant d’installer, car en quittant il enregistrerait ses propres préférences par-dessus celles écrites par AddonVisor.

2 · Cocher les add-ons

  • Cliquez sur une case vide de la colonne cible pour mettre cet add-on en attente ; cliquez à nouveau pour le retirer.
  • Cliquez et glissez le long de la colonne pour en cocher plusieurs d’un coup.
  • Ou utilisez un raccourci : Ma config 5.1 + 5.2 → 5.3 (tout ce qui est activé dans vos deux versions les plus récentes), Tout ce qui marche → 5.3, ou Effacer.
  • Les add-ons installés mais jamais activés sont masqués sous Afficher N add-ons jamais activés.

Quelle copie est utilisée

Vous ne choisissez jamais de version source. Pour chaque add-on, AddonVisor examine toutes les copies présentes sur votre PC et utilise, dans cet ordre :

  1. votre copie corrigée, si vous avez réparé l’add-on (voir Réparer sur une copie) ;
  2. une version compatible plus récente sur extensions.blender.org — si elle existe, ou si votre copie locale est connue pour échouer. La ligne indique « ↑ 11.0.12 sur extensions.blender.org · sera utilisée » et Blender la télécharge lui-même ;
  3. sinon, la copie locale la plus récente qui déclare prendre en charge la cible (blender_version_min/max ou bl_info["blender"]).

3 · Installer et tester

Appuyez sur Installer et tester (N).

  1. Test en bac à sable. Le dossier utilisateur de la cible est copié dans un dossier temporaire, et Blender est lancé sur cette copie. Les add-ons y sont copiés et activés un par un. Rien ne change dans vos vrais dossiers Blender. Les add-ons GPU sont retestés avec une petite fenêtre — vous la verrez peut-être apparaître brièvement.
  2. Résultats. Vous voyez ce qui fonctionne et ce qui échoue, avec la vraie erreur Python. Choisissez ensuite Installer les N qui fonctionnent, Réparer à côté d’un add-on en échec, ou Annuler.

Annulation et sauvegardes

Avant une installation réelle, AddonVisor sauvegarde vos préférences et chaque fichier qu’il remplace.

  • Dans la fenêtre des résultats : ↶ Annuler.
  • Plus tard : ↶ Annuler la dernière installation dans le panneau Version cible.

L’annulation supprime ce qui a été ajouté, remet en place ce qui a été remplacé et restaure vos préférences (ou les supprime, si ce Blender n’en avait pas auparavant).

4Réparer les add-ons

Réparer sur une copie

Quand un add-on échoue, appuyez sur Réparer à côté de lui. AddonVisor crée une copie corrigée et y applique votre correction — l’original n’est jamais modifié.

Ce que vous fournissezCe qui se passe
Un diff (.diff, .patch)Repéré grâce au code environnant ; les numéros de ligne sont ignorés, donc les diffs écrits par une IA fonctionnent
Une réponse complète d’un chat IA (.md ou texte collé)Chaque bloc ```diff qu’elle contient est appliqué
Un fichier .py completRemplace le fichier du même nom dans l’add-on
Un .zip de l’add-on réparéRemplace toute la copie

Déposez un fichier dans la zone, cliquez dessus pour en choisir un, ou collez du texte et appuyez sur Appliquer le texte collé. Les patchs de n’importe quelle IA fonctionnent — Claude, ChatGPT, Gemini, Copilot. Appuyez ensuite sur ↻ Retester dans le bac à sable. Si l’assistant intégré a répondu avec un diff, Appliquer les patchs de l’IA et retester fait tout en un clic.

D’où viennent les patchs ?

Vous n’avez pas à écrire de code. Trois façons, de la plus simple :

  1. L’assistant intégré (Claude, Gemini ou une IA locale — voir Assistant IA). Après un test échoué, il lit le journal tout seul ; si sa réponse contient un diff, Appliquer les patchs de l’IA et retester l’applique et reteste en un clic.
  2. N’importe quel chat IA, avec Générer le prompt IA. Le bouton se trouve dans la fenêtre des résultats et dans le panneau IA, et fonctionne même assistant désactivé. Il rédige une demande détaillée en anglais : les versions de Blender et de Python des deux côtés, votre système, le type d’add-on et ses fichiers, l’erreur complète et le code fautif — plus des règles précises de format de patch, pour que la réponse s’applique automatiquement. Choisissez la formulation : Correctif minimal, Ancien + nouveau, Explication seule (sans code, seulement la cause et vos options), Revue complète (tout ce qui va casser, pas seulement la première erreur) ou Diff seul (IA locale). Vous pouvez modifier le texte, puis appuyez sur Copier le prompt, collez-le dans ChatGPT, Claude, Gemini, Copilot ou une autre IA, copiez toute sa réponse et collez-la dans Réparer → Appliquer le texte collé → Retester dans le bac à sable.
  3. Votre propre demande. Copier le rapport pour l’IA copie seulement le court rapport d’erreur ; ajoutez-y votre question.
Si le patch de l’IA ne s’applique pas (« hunk N does not match »), renvoyez ce message dans la même conversation et demandez-lui de recopier exactement les lignes de contexte du code fourni. Si une nouvelle erreur apparaît après la première correction, choisissez Revue complète.

Règles de sécurité

  • Tout ou rien. Si une partie d’un patch ne correspond pas, rien n’est écrit et on vous indique le fichier et la ligne.
  • Pas de double patch. Un patch déjà appliqué est refusé.
  • L’indentation compte. En Python, elle change le sens du code ; elle doit donc correspondre (tabulations ou 4 espaces : la différence est tolérée).
Un patch reste sur votre ordinateur. Pour les add-ons payants, une mise à jour de l’auteur est généralement la voie la plus sûre — envoyez-lui le rapport qui se trouve dans …/extensions/.user/user_default/addonvisor/logs/.

La liste des patchs

Les lignes avec des patchs affichent ▸. Cliquez dessus pour voir chaque patch : numéro, nom du fichier, fichiers modifiés et date.

  • ✕ Retirer annule un seul patch : la copie est reconstruite à partir de l’original et les autres patchs sont réappliqués, dans l’ordre. Si un patch ultérieur en dépend, rien ne change et on vous indique lequel retirer d’abord.
  • ↺ Réinitialiser les patchs — ou le petit ↺ à côté de la note — supprime la copie corrigée ; l’original est de nouveau utilisé.

Exemple : BlenderGIS dans Blender 5.3

Blender 5.3 embarque Python 3.13, qui a supprimé le module imghdr. BlenderGIS 2.2.10 l’utilise dans deux fichiers et échoue avec ModuleNotFoundError: No module named 'imghdr'. Ce patch continue d’utiliser imghdr là où il existe et, sinon, se rabat sur une petite vérification de l’en-tête :

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

Téléchargez le patch complet : BlenderGIS_2.2.10_python313_imghdr.diff — puis Réparer → déposez le fichier → Retester.

5Assistant IA

Connexion et utilisation

Facultatif. Après un test en échec, il lit le rapport d’erreurs et explique ce qui ne marche pas et comment le réparer, généralement avec un diff prêt à l’emploi. Sans lui, AddonVisor fonctionne entièrement et rien ne quitte votre ordinateur.

Gemini — clé gratuite avec votre compte Google

  1. Appuyez sur Continuer avec Google ; Google AI Studio s’ouvre dans votre navigateur.
  2. Connectez-vous, appuyez sur Créer une clé API et copiez-la.
  3. Collez-la dans AddonVisor et appuyez sur Connecter.

Claude — clé API payante

  1. Appuyez sur Obtenir une clé API Claude ; la Claude Console s’ouvre.
  2. Ajoutez du crédit sous Billing, puis créez une clé sous API keys (elle n’est affichée qu’une seule fois).
  3. Collez-la et appuyez sur Connecter. Un abonnement Claude Pro/Max n’inclut pas l’utilisation de l’API ; une analyse coûte quelques centimes.

IA locale — sur votre PC, gratuite

  1. Installez Ollama (ou LM Studio, llama.cpp, Jan) et téléchargez un modèle, par ex. ollama pull gemma4:e4b.
  2. Dans AddonVisor, choisissez Local, gardez l’adresse http://localhost:11434/v1 (LM Studio : http://localhost:1234/v1) et appuyez sur Trouver les modèles.
  3. Choisissez un modèle et appuyez sur Connecter.

Rien ne quitte votre ordinateur. Les petits modèles sont rapides mais proposent des corrections plus faibles — retestez toujours dans le bac à sable ; les grands modèles (ou Claude / Gemini) sont plus fiables. Tout serveur compatible OpenAI fonctionne aussi, y compris en ligne avec une clé API.

Utilisation

  • Lire le journal automatiquement après chaque test (activé par défaut) : la réponse apparaît dans la fenêtre des résultats.
  • Ou appuyez sur Demander à l’IA.
  • Si un modèle est surchargé, AddonVisor patiente et en essaie un autre tout seul ; si cela échoue encore, appuyez sur ↻ Réessayer.

Ce qui est envoyé à l’IA

Uniquement le rapport des add-ons en échec : l’erreur Python et environ 17 lignes de code autour de la ligne fautive. Les chemins contenant votre nom d’utilisateur sont remplacés par %USERPROFILE% (Linux, macOS : ~). Les clés sont gardées dans le dossier de l’extension : sous Windows, chiffrées pour votre utilisateur Windows (DPAPI) ; sous Linux et macOS, dans un fichier lisible uniquement par votre utilisateur. Déconnecter les supprime. Modèles : Claude claude-opus-5-5 ; Gemini — le modèle Flash le plus récent accessible avec votre clé. Avec Local, le rapport va seulement au serveur IA de votre ordinateur.

6Référence

Fichiers et dossiers

Tout se trouve dans le dossier propre de l’extension, dans le dossier utilisateur du Blender qui l’exécute — pour Blender 5.3 sous Windows : %APPDATA%\Blender Foundation\Blender\5.3\extensions\.user\user_default\addonvisor\ (Linux : ~/.config/blender/5.3/extensions/.user/user_default/addonvisor/ ; macOS : ~/Library/Application Support/Blender/5.3/extensions/.user/user_default/addonvisor/).

Confidentialité

  • La page ne fonctionne que sur votre ordinateur (127.0.0.1, lien privé qui change à chaque fois).
  • Pas de compte, pas de télémétrie, pas de statistiques d’utilisation.
  • Réseau uniquement pour extensions.blender.org (quelles extensions existent, et téléchargements via Blender) et pour le fournisseur d’IA que vous avez connecté.
  • Tout le reste reste sur votre ordinateur.
  • Avec une IA locale (Ollama, LM Studio…), le rapport ne quitte jamais votre ordinateur.

FAQ

Est-ce un add-on Blender ?

Oui — une extension Blender (Blender 4.2+). Sa page s’ouvre dans votre navigateur web, et elle lit toutes les versions de Blender de votre ordinateur, pas seulement celle dans laquelle vous êtes. Il existe aussi une application de bureau séparée pour Windows et Linux : guide de l’application de bureau.

Peut-il casser ma configuration Blender ?

Tout est d’abord testé dans un bac à sable ; les installations réelles demandent votre confirmation, font une sauvegarde et peuvent être annulées.

Répare-t-il les add-ons automatiquement ?

Il utilise une version compatible plus récente depuis extensions.blender.org quand il en existe une ; sinon, vous appliquez un patch (de l’IA intégrée ou de n’importe quelle autre) sur une copie et vous retestez. Certains add-ons nécessitent l’intervention de leur auteur.

Fonctionne-t-il avec les add-ons que j’ai achetés ?

Oui — il copie ce qui est installé sur votre PC et ne partage jamais vos add-ons.

Windows, Linux, macOS ?

Testé sous Windows et Linux. macOS devrait fonctionner mais n’a pas encore été testé sur un Mac.

Puis-je aussi installer dans des versions plus anciennes de Blender ?

Oui. N’importe quel Blender de votre ordinateur peut être la cible, y compris des versions antérieures à 4.2 — il suffit qu’elles soient fermées pendant qu’AddonVisor installe.

Le code source est-il inclus ?

Oui. AddonVisor est distribué sous licence GNU GPL v3 ; l’extension est en Python pur, donc le téléchargement est le code source.
