AddonVisor

Руководство пользователя · версия 1.0.0 · Windows 10/11 · проверено с Blender 4.1 – 5.3
1Обзор

Что это такое

Выходит новый Blender, вы его устанавливаете — а ваших аддонов там нет. Вы переносите их по одному, включаете и узнаёте, какие сломались, только когда они понадобятся.

AddonVisor — небольшое приложение для Windows, которое делает это за вас, вне Blender. Оно находит все версии Blender на компьютере, показывает, какие аддоны вы используете в каждой, переносит их в выбранную версию, проверяет их в песочнице до любых изменений и точно сообщает, что сломалось и почему, — с исправлением, если оно есть.

Принципы

Вне Blender — поэтому видит всё

Аддон внутри Blender видит только одну эту версию. AddonVisor работает самостоятельно, поэтому может сравнить все ваши версии Blender сразу — даже те, которые вы ни разу не открывали.

Сначала проверка, потом изменения

Ничего не устанавливается по-настоящему, пока не заработает во временной копии настроек целевой версии. Вы решаете, что устанавливать, уже увидев результат.

Оригиналы не трогаются

Из старых версий Blender только читается. Исправления делаются на копии. У каждой настоящей установки есть резервная копия и отмена.

Минимум кликов

Приложение само сканирует компьютер, выбирает целевой версией самый новый Blender, а для каждого аддона — самую новую копию. Большинство переносов — два клика: вариант быстрого выбора, затем Установить и проверить.

Для кого

ПодойдётВсем, у кого несколько версий Blender и больше пары-тройки аддонов; студиям, переводящим команду на новый релиз; разработчикам аддонов, которые хотят видеть, где их аддон ломается.
Подойдёт меньшеЕсли у вас один Blender и два-три аддона, может хватить встроенной функции Blender Import previous settings. macOS и Linux пока не поддерживаются.
2Начало работы

Установка

Требования

  • Windows 10 или 11, 64-бит
  • Microsoft Edge WebView2 Runtime — встроен в Windows 11 и обычно есть в Windows 10
  • Одна или несколько установленных версий Blender. Проверено с 4.1 – 5.3; 2.8x – 4.0 должны работать, но не проверялись.
  • Интернет нужен только для загрузок с extensions.blender.org и для необязательного ИИ-помощника

Установщик

Запустите AddonVisor-Setup-1.0.0.exe. Права администратора не нужны. AddonVisor появится в меню «Пуск» и в разделе Параметры → Приложения, откуда его можно удалить.

Портативная версия

Распакуйте AddonVisor-1.0.0-portable.zip в любую папку и запустите AddonVisor.exe. В архиве также есть полный исходный код.

Windows SmartScreen при первом запуске может показать «Система Windows защитила ваш компьютер», потому что приложение новое и пока не подписано цифровой подписью. Нажмите Подробнее → Выполнить в любом случае. Это нужно сделать только один раз.

Первый запуск

  1. AddonVisor сам сканирует компьютер: Program Files, Steam, реестр Windows и папки портативных Blender. Каждый Blender незаметно запускается в фоне, чтобы прочитать его аддоны, — это занимает несколько секунд.
  2. Появляется матрица. Самый новый Blender выбран целевой версией.
  3. Язык меняется кнопкой в правом верхнем углу: English, Français, Español, Deutsch, Русский, 简体中文, 日本語, Português (Brasil), Română. Кнопка Справка открывает это руководство.

Как читать матрицу

СимволЗначение
✓включён и работает в этой версии Blender
○установлен, но выключен
✕включён, но не загружается — наведите курсор, чтобы увидеть ошибку
!GPU-аддон: не может загрузиться в фоне, перепроверяется с маленьким окном
+в очереди: будет установлен в целевую версию

Столбец Новейшая копия показывает самую новую версию аддона, найденную на компьютере, и из какого Blender она взята. Пометки под названием сообщают, если на extensions.blender.org есть более новая версия, если версия заведомо не работает или если у вас есть исправленная копия.

3Порядок работы

1 · Выберите целевую версию

Нажмите на заголовок столбца, чтобы сделать этот Blender целевой версией. По умолчанию это самая новая установленная версия — даже если вы её ни разу не открывали.

2 · Отметьте аддоны

  • Щёлкните пустую ячейку в целевом столбце, чтобы поставить аддон в очередь; щёлкните ещё раз, чтобы убрать его.
  • Зажмите и протяните вниз по столбцу, чтобы отметить несколько сразу.
  • Или используйте быстрый выбор: Мой набор 5.1 + 5.2 → 5.3 (всё, что включено в двух последних версиях), Всё, что работает → 5.3 или Сбросить.
  • Аддоны, которые вы установили, но ни разу не включали, скрыты под строкой Показать N ни разу не включённых аддонов.

Какая копия используется

Исходную версию выбирать не нужно. Для каждого аддона AddonVisor просматривает все копии на компьютере и использует, в таком порядке:

  1. вашу исправленную копию, если вы исправляли аддон (см. Исправление на копии);
  2. более новую совместимую версию с extensions.blender.org — если она есть или если ваша локальная копия заведомо не работает. В строке написано «↑ 11.0.12 на extensions.blender.org · будет использована», и Blender сам её скачивает;
  3. иначе — самую новую локальную копию, которая заявляет поддержку целевой версии (blender_version_min/max или bl_info["blender"]).

3 · Установка и проверка

Нажмите Установить и проверить (N).

  1. Проверка в песочнице. Пользовательская папка целевой версии копируется во временную папку, и Blender запускается с этой копией. Аддоны копируются туда и включаются по одному. В ваших настоящих папках Blender ничего не меняется. GPU-аддоны перепроверяются с маленьким окном — оно может мелькнуть.
  2. Результаты. Вы видите, что работает, а что нет, с настоящей ошибкой Python. Затем выберите Установить N рабочих, Исправить рядом с аддоном с ошибкой или Отмена.

Отмена и резервные копии

Перед настоящей установкой AddonVisor сохраняет ваши настройки и каждый файл, который заменяет.

  • В окне результатов: ↶ Отменить.
  • Позже: ↶ Отменить последнюю установку в карточке Целевая версия.

Отмена удаляет добавленное, возвращает заменённое и восстанавливает ваши настройки (или удаляет их, если раньше в этом Blender их не было).

4Исправление аддонов

Исправление на копии

Если аддон не работает, нажмите Исправить рядом с ним. AddonVisor создаёт исправленную копию и применяет исправление к ней — оригинал никогда не редактируется.

Что вы даётеЧто происходит
Diff (.diff, .patch)Сопоставляется по окружающему коду; номера строк игнорируются, поэтому diff, написанные ИИ, подходят
Целый ответ ИИ-чата (.md или вставленный текст)Применяется каждый блок ```diff из него
Целый файл .pyЗаменяет файл с тем же именем внутри аддона
.zip исправленного аддонаЗаменяет всю копию

Перетащите файл в поле, щёлкните по нему, чтобы выбрать файл, или вставьте текст и нажмите Применить вставленный текст. Подходят патчи от любого ИИ — Claude, ChatGPT, Gemini, Copilot. Затем нажмите ↻ Проверить снова в песочнице. Если встроенный помощник ответил с diff, кнопка Применить патчи ИИ и проверить снова делает всё в один клик.

Правила безопасности

  • Всё или ничего. Если часть патча не совпадает, ничего не записывается, и вам сообщают, в каком файле и на какой строке.
  • Без двойных патчей. Уже применённый патч отклоняется.
  • Отступы важны. В Python они меняют смысл, поэтому должны совпадать (табуляция вместо 4 пробелов допускается).
Патч остаётся на вашем компьютере. Для платных аддонов обычно надёжнее обновление от автора — отправьте ему отчёт из %LOCALAPPDATA%\AddonVisor\logs\.

Список патчей

У строк с патчами есть значок ▸. Нажмите на него, чтобы увидеть все патчи: номер, имя файла, какие файлы он изменил и когда.

  • ✕ Убрать отменяет один патч: копия пересобирается из оригинала, и остальные патчи применяются заново по порядку. Если от него зависит более поздний патч, ничего не меняется, и вам сообщают, какой убрать сначала.
  • ↺ Сбросить все патчи — или маленький ↺ рядом с пометкой — удаляет исправленную копию; снова используется оригинал.

Пример: BlenderGIS в Blender 5.3

Blender 5.3 поставляется с Python 3.13, в котором удалён модуль imghdr. BlenderGIS 2.2.10 использует его в двух файлах и падает с ошибкой ModuleNotFoundError: No module named 'imghdr'. Этот патч по-прежнему использует imghdr, где он есть, а в остальных случаях переходит к простой проверке заголовка файла:

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

Скачайте полный патч: BlenderGIS_2.2.10_python313_imghdr.diff — затем Исправить → перетащите файл → Проверить снова.

5ИИ-помощник

Подключение и использование

Необязательно. После неудачной проверки помощник читает отчёт об ошибках и объясняет, что сломалось и как это исправить, обычно с готовым diff. Без него AddonVisor полностью работает, и ничего не покидает ваш компьютер.

Gemini — бесплатный ключ через аккаунт Google

  1. Нажмите Продолжить с Google; в браузере откроется Google AI Studio.
  2. Войдите, нажмите Create API key и скопируйте ключ.
  3. Вставьте его в AddonVisor и нажмите Подключить.

Claude — платный API-ключ

  1. Нажмите Получить API-ключ Claude; откроется Claude Console.
  2. Пополните баланс в разделе Billing, создайте ключ в разделе API keys (он показывается только один раз).
  3. Вставьте его и нажмите Подключить. Подписка Claude Pro/Max не включает использование API; один анализ стоит несколько центов.

Локальный ИИ — на вашем ПК, бесплатно

  1. Установите Ollama (или LM Studio, llama.cpp, Jan) и скачайте модель, например ollama pull gemma4:e4b.
  2. В AddonVisor выберите Локально, оставьте адрес http://localhost:11434/v1 (LM Studio: http://localhost:1234/v1) и нажмите Найти модели.
  3. Выберите модель и нажмите Подключить.

Ничего не покидает ваш компьютер. Небольшие модели работают быстро, но предлагают более слабые исправления — всегда проверяйте снова в песочнице; крупные модели (или Claude / Gemini) надёжнее. Подойдёт и любой OpenAI-совместимый сервер, в том числе онлайн с API-ключом.

Использование

  • Автоматически читать журнал после каждой проверки (включено по умолчанию): ответ появляется в окне результатов.
  • Или нажмите Спросить ИИ об ошибках.
  • Если модель перегружена, AddonVisor ждёт и сам пробует другую; если ошибка не уходит, нажмите ↻ Повторить.

Что отправляется ИИ

Только отчёт по аддонам с ошибками: ошибка Python и около 17 строк кода вокруг строки с ошибкой. Пути, содержащие ваше имя пользователя Windows, заменяются на %USERPROFILE%. Ключи хранятся в зашифрованном виде для вашей учётной записи Windows (DPAPI); кнопка Отключить удаляет их. Модели: Claude — claude-opus-5-5; Gemini — самая новая модель Flash, доступная вашему ключу. В режиме Локально отчёт уходит только на ИИ-сервер вашего ПК.

6Справочник

Файлы и папки

Всё хранится в %LOCALAPPDATA%\AddonVisor\ и сохраняется при удалении программы, так что резервные копии не пропадут.

Папка / файлСодержимое
backups\резервная копия перед каждой настоящей установкой (используется для отмены)
logs\run_*.log и ai_report_*.md для каждой проверки
patched\ваши исправленные копии аддонов со всеми применёнными патчами
settings.jsonязык, настройки ИИ, дополнительные папки Blender
keys.jsonключи ИИ, зашифрованные для вашей учётной записи Windows

Конфиденциальность

  • Без учётной записи, без телеметрии, без аналитики.
  • Сеть используется только для extensions.blender.org (какие расширения существуют и загрузки через Blender) и для подключённого вами ИИ-провайдера.
  • Всё остальное остаётся на вашем компьютере.
  • С локальным ИИ (Ollama, LM Studio…) отчёт никогда не покидает ваш ПК.

Чтобы сообщить о проблеме, приложите самый новый run_*.log из %LOCALAPPDATA%\AddonVisor\logs\ и перечислите свои версии Blender: GitHub Issues или gmcis.cutvisor@gmail.com.

Вопросы и ответы

Это аддон для Blender?

Нет — отдельное приложение для Windows. Поэтому оно видит все ваши версии Blender сразу.

Может ли оно испортить мои настройки Blender?

Всё сначала проверяется в песочнице; настоящая установка требует вашего подтверждения, создаёт резервную копию и может быть отменена.

Исправляет ли оно аддоны автоматически?

Оно использует более новую совместимую версию с extensions.blender.org, если она есть; иначе вы применяете патч (от встроенного ИИ или любого другого) к копии и проверяете снова. Некоторые аддоны может исправить только их автор.

Работает ли оно с купленными аддонами?

Да — оно копирует то, что установлено на вашем компьютере, и никому не передаёт ваши аддоны.

Mac / Linux?

Пока нет.

Исходный код включён?

Да. AddonVisor распространяется по лицензии GNU GPL v3; исходный код входит в загрузку.
