AddonVisor

ユーザーガイド · バージョン 1.0.0 · Windows 10/11 · Blender 4.1 – 5.3 でテスト済み
1概要

AddonVisor とは

新しい Blender が出たのでインストールしてみると、アドオンが入っていません。1 つずつコピーして有効にし、どれが壊れているかに気づくのは実際に必要になったときです。

AddonVisor は、この作業をBlender の外から代わりに行う小さな Windows アプリです。PC 上のすべての Blender を見つけ、それぞれで使っているアドオンを表示し、選んだバージョンへ移します。何かを変更する前にサンドボックスでテストし、何がなぜ壊れたのかを正確に示します。修正方法があればそれも提示します。

設計思想

Blender の外で動くので、すべてが見える

Blender 内のアドオンには、そのバージョンしか見えません。AddonVisor は単独で動作するため、一度も開いたことのないバージョンも含め、すべての Blender バージョンを一度に比較できます。

先にテスト、変更は後で

対象の設定の使い捨てコピーで動作を確認するまで、実際には何もインストールされません。結果を見てから、何をインストールするかを決められます。

オリジナルには触れない

古い Blender バージョンは読み取るだけです。修正はコピー上で行います。実際のインストールには必ずバックアップと「元に戻す」があります。

少ないクリック

スキャンは自動で行われ、最新の Blender を対象に、各アドオンの最新のコピーを選びます。ほとんどの移行は 2 クリックで済みます：ショートカットを選び、インストールしてテストを押すだけです。

対象ユーザー

向いている人複数の Blender バージョンと多数のアドオンを使っている方、チームを新しいリリースへ移行するスタジオ、自分のアドオンがどこで壊れるかを確認したいアドオン開発者。
あまり向いていない人Blender が 1 つでアドオンが 2～3 個だけなら、Blender 自体の Import previous settings で十分かもしれません。macOS と Linux にはまだ対応していません。
2はじめに

インストール

動作環境

  • Windows 10 または 11（64 ビット）
  • Microsoft Edge WebView2 Runtime — Windows 11 には標準搭載、Windows 10 にも通常はインストール済み
  • 1 つ以上の Blender バージョン。4.1 – 5.3 でテスト済みです。2.8x – 4.0 も動作するはずですが未テストです。
  • インターネット接続が必要なのは、extensions.blender.org からのダウンロードと任意の AI アシスタントのみ

インストーラー

AddonVisor-Setup-1.0.0.exe を実行します。管理者権限は不要です。AddonVisor はスタート メニューと設定 → アプリに表示され、そこからアンインストールできます。

ポータブル版

AddonVisor-1.0.0-portable.zip を任意の場所に展開し、AddonVisor.exe を実行します。zip には完全なソースコードも含まれています。

初回起動時に Windows SmartScreen が「Windows によって PC が保護されました」と表示することがあります。アプリが新しく、まだコード署名されていないためです。詳細情報 → 実行をクリックしてください。これは一度だけで済みます。

初回起動

  1. AddonVisor は PC を自動でスキャンします：Program Files、Steam、Windows レジストリ、ポータブル版 Blender のフォルダー。各 Blender をバックグラウンドで非表示のまま起動してアドオンを読み取るため、数秒かかります。
  2. マトリクスが表示されます。最新の Blender が対象として選ばれています。
  3. 右上のボタンで言語を変更できます：English、Français、Español、Deutsch、Русский、简体中文、日本語、Português (Brasil)、Română。ヘルプボタンでこのガイドが開きます。

マトリクスの見方

記号意味
✓その Blender バージョンで有効になっており、動作している
○インストール済みだが無効
✕有効だが読み込みに失敗 — マウスを重ねるとエラーを表示
!GPU アドオン：バックグラウンドでは読み込めないため、小さなウィンドウで再テスト
+予定：対象バージョンにインストールされる

最新コピー列には、PC 上で見つかったそのアドオンの最新バージョンと、それがどの Blender にあるかが表示されます。名前の下の注記は、extensions.blender.org に新しいバージョンがあるとき、そのバージョンが失敗することがわかっているとき、または修正済みコピーがあるときに表示されます。

3ワークフロー

1 · 対象を選ぶ

列の見出しをクリックすると、その Blender が対象になります。既定ではインストール済みの最新バージョンが選ばれます — 一度も開いたことがなくても対象になります。

2 · アドオンにチェックを入れる

  • 対象列の空のセルをクリックするとそのアドオンが予定に入り、もう一度クリックすると外れます。
  • 列に沿って押したまま下へドラッグすると、まとめてチェックできます。
  • またはショートカット：5.1 + 5.2 の構成 → 5.3（直近 2 バージョンで有効なものすべて）、動くものすべて → 5.3、クリア。
  • インストールしたものの一度も有効にしていないアドオンは、一度も有効にしていない N 個を表示の中に隠れています。

使用されるコピー

ソースのバージョンを選ぶ必要はありません。AddonVisor は各アドオンについて PC 上のすべてのコピーを調べ、次の順で使用します：

  1. アドオンを修正した場合は、その修正済みコピー（コピー上で修正を参照）。
  2. extensions.blender.org にある互換性のある新しいバージョン — 存在する場合、またはローカルのコピーが失敗することがわかっている場合。行には「↑ extensions.blender.org に 11.0.12 · こちらを使用」と表示され、Blender 自身がダウンロードします。
  3. それ以外は、対象への対応を宣言している最新のローカルコピー（blender_version_min/max または bl_info["blender"]）。

3 · インストールしてテスト

インストールしてテスト（N）を押します。

  1. サンドボックステスト。対象のユーザーフォルダーを一時フォルダーにコピーし、そのコピーを参照するように Blender を起動します。アドオンを 1 つずつコピーして有効にします。実際の Blender フォルダーは何も変更されません。GPU アドオンは小さなウィンドウで再テストされるため、一瞬表示されることがあります。
  2. 結果。何が動作し何が失敗したかが、実際の Python エラーとともに表示されます。動作する N 個をインストール、失敗したアドオンの横の修正、またはキャンセルを選びます。

元に戻す・バックアップ

実際にインストールする前に、AddonVisor はプリファレンスと、置き換えるすべてのファイルを保存します。

  • 結果ウィンドウで：↶ 元に戻す。
  • 後から：対象バージョンカードの↶ 前回のインストールを取り消す。

元に戻すと、追加したものが削除され、置き換えたものが復元され、プリファレンスも元に戻ります（その Blender に以前プリファレンスがなかった場合は削除されます）。

4アドオンの修正

コピー上で修正

アドオンが失敗したら、その横の修正を押します。AddonVisor は修正済みコピーを作り、そこに修正を適用します — オリジナルが編集されることはありません。

渡すもの処理内容
diff（.diff、.patch）周囲のコードで照合します。行番号は無視するため、AI が書いた diff も使えます
AI チャットの回答全体（.md または貼り付けたテキスト）含まれるすべての ```diff ブロックを適用します
.py ファイル全体アドオン内の同名ファイルを置き換えます
修正済みアドオンの .zipコピー全体を置き換えます

ファイルをボックスにドロップするか、クリックして選ぶか、テキストを貼り付けて貼り付けた内容を適用を押します。どの AI のパッチでも使えます — Claude、ChatGPT、Gemini、Copilot。その後、↻ サンドボックスで再テストを押します。内蔵アシスタントが diff で回答した場合は、AI のパッチを適用して再テストでワンクリックで済みます。

安全のためのルール

  • 全部か、何もしないか。パッチの一部でも一致しなければ何も書き込まず、どのファイルのどの行かを表示します。
  • 二重適用しない。すでに適用済みのパッチは拒否されます。
  • インデントは重要。Python ではインデントで意味が変わるため、一致している必要があります（タブと 4 スペースの違いは許容されます）。
パッチはあなたのコンピューター内にだけ残ります。有料アドオンの場合は、通常は作者による更新のほうが安全です — %LOCALAPPDATA%\AddonVisor\logs\ のレポートを作者に送ってください。

パッチ一覧

パッチのある行には ▸ が表示されます。クリックすると、すべてのパッチ（番号、ファイル名、変更したファイル、日時）が表示されます。

  • ✕ 削除はパッチを 1 つ取り消します：オリジナルからコピーを作り直し、残りのパッチを順に再適用します。後のパッチがそれに依存している場合は何も変更せず、先に削除すべきパッチを表示します。
  • ↺ すべてのパッチをリセット — または注記の横の小さな ↺ — は修正済みコピーを削除し、再びオリジナルが使われるようにします。

例：Blender 5.3 での BlenderGIS

Blender 5.3 には Python 3.13 が同梱されており、imghdr モジュールが削除されています。BlenderGIS 2.2.10 は 2 つのファイルでこれを使っているため、ModuleNotFoundError: No module named 'imghdr' で失敗します。次のパッチは、imghdr があればそれを使い、なければ簡単なヘッダーチェックで代用します：

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

パッチ全体をダウンロード：BlenderGIS_2.2.10_python313_imghdr.diff — その後、修正 → ファイルをドロップ → 再テスト。

5AI アシスタント

接続と使い方

任意の機能です。テストが失敗すると、エラーレポートを読んで何が壊れたか、どう直すかを説明し、たいていはそのまま使える diff も示します。使わなくても AddonVisor のすべての機能が使え、データがコンピューターの外に出ることはありません。

Gemini — Google アカウントで無料キー

  1. Google で続行を押すと、ブラウザで Google AI Studio が開きます。
  2. ログインして Create API key（API キーを作成）を押し、キーをコピーします。
  3. AddonVisor に貼り付けて接続を押します。

Claude — 有料 API キー

  1. Claude API キーを取得を押すと、Claude Console が開きます。
  2. Billing でクレジットを追加し、API keys でキーを作成します（キーは一度しか表示されません）。
  3. 貼り付けて接続を押します。Claude Pro/Max のサブスクリプションには API の利用は含まれません。分析 1 回の費用は数セントです。

使い方

  • テストのたびにログを自動で読む（既定でオン）：回答が結果ウィンドウに表示されます。
  • またはAI にエラーを聞くを押します。
  • モデルが混雑している場合、AddonVisor は待機して別のモデルを自動で試します。それでも失敗したら↻ 再試行を押してください。

AI に送信される内容

送信されるのは失敗したアドオンのレポートだけです：Python エラーと、失敗した行の前後約 17 行のコード。Windows のユーザー名を含むパスは %USERPROFILE% に置き換えられます。キーは Windows ユーザーごとに暗号化して保存され（DPAPI）、切断で削除されます。モデル：Claude は claude-opus-5-5、Gemini はキーで利用できる最新の Flash モデルです。

6リファレンス

ファイルとフォルダー

すべて %LOCALAPPDATA%\AddonVisor\ に保存され、アンインストールしても残るため、バックアップは失われません。

フォルダー / ファイル内容
backups\実際のインストールごとのバックアップ（元に戻すで使用）
logs\テストごとの run_*.log と ai_report_*.md
patched\アドオンの修正済みコピーと、適用したすべてのパッチ
settings.json言語、AI の設定、追加の Blender フォルダー
keys.jsonAI キー（Windows ユーザーごとに暗号化）

プライバシー

  • アカウント不要、テレメトリなし、アクセス解析なし。
  • ネットワークを使うのは extensions.blender.org（どの拡張機能があるかの確認と、Blender 経由のダウンロード）と、接続した AI プロバイダーだけです。
  • それ以外はすべて PC 内に留まります。

トラブルシューティング

問題対処法
Blender のバージョンが表示されないそのフォルダーを settings.json に追加します：{"extra_dirs": ["D:\\Apps\\blender-5.3"]}。その後、再スキャンします。Microsoft Store 版には対応していません。
テスト中に Blender のウィンドウが一瞬表示される正常です：GPU アドオンはウィンドウ付きで再テストされます。ウィンドウは自動で閉じます。
「AI に接続できません：… high demand」プロバイダーが混雑しています。他のモデルもすでに試しています。しばらくしてから↻ 再試行を押してください。
「hunk N does not match the file」パッチが別のコード向けに書かれています（別のバージョン、またはコピーがすでに修正済み）。▸ を開き、パッチを削除またはリセットしてからやり直してください。
「this patch is already applied」対処は不要です — その変更はすでにコピーに含まれています。
「could not delete … a file is in use」patched\ 内のファイルを開いているエクスプローラーやエディターを閉じてから、再試行してください。
ウィンドウが真っ白Microsoft Edge WebView2 Runtime をインストールまたは修復してください。
SmartScreen / ウイルス対策ソフトの警告詳細情報 → 実行。必要なら検疫から復元してください — 誤検知として報告できるよう、ぜひお知らせください。

問題を報告するときは、%LOCALAPPDATA%\AddonVisor\logs\ の最新の run_*.log を添付し、お使いの Blender バージョンを書いてください：GitHub Issues または gmcis.cutvisor@gmail.com。

よくある質問

これは Blender のアドオンですか？

いいえ — 独立した Windows アプリです。だからこそ、すべての Blender バージョンを一度に見られます。

Blender の環境を壊すことはありますか？

すべてまずサンドボックスでテストします。実際のインストールにはあなたの確認が必要で、バックアップを取り、元に戻すこともできます。

アドオンを自動で修正しますか？

extensions.blender.org に互換性のある新しいバージョンがあればそれを使います。なければ、パッチ（内蔵 AI でも他の AI でも可）をコピーに適用して再テストします。作者の対応が必要なアドオンもあります。

購入したアドオンにも使えますか？

はい — PC にインストールされているものをコピーするだけで、アドオンを共有することはありません。

Mac / Linux は？

まだ対応していません。

ソースコードは含まれていますか？

はい。AddonVisor は GNU GPL v3 でライセンスされており、ダウンロードにソースが含まれています。
