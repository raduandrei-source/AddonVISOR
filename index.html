AddonVisor

User Guide · version 0.3.3 · Windows 10/11 · tested with Blender 4.1 – 5.3
1Overview

What it is

A new Blender comes out, you install it — and your add-ons are not there. You copy them over one by one, enable them, and discover which ones broke only when you need them.

AddonVisor is a small Windows app that does this for you, from outside Blender. It finds every Blender on your PC, shows which add-ons you use in each one, moves them to the version you choose, tests them in a sandbox before anything changes, and tells you exactly what broke and why — with a fix when there is one.

Philosophy

Outside Blender, so it sees everything

An add-on inside Blender only sees that one version. AddonVisor runs on its own, so it can compare all your Blender versions at once — including ones you have never opened.

Test first, change later

Nothing is installed for real until it has worked in a throw-away copy of the target's settings. You decide what to install after you have seen the result.

Never touch the originals

Older Blender versions are only read from. Fixes are made on a copy. Every real install has a backup and an Undo.

Few clicks

It scans by itself, picks the newest Blender as target and the newest copy of each add-on. Most migrations are two clicks: a shortcut, then Install & test.

Who it's for

Good fitAnyone with several Blender versions and more than a handful of add-ons; studios moving a team to a new release; add-on developers who want to see where their add-on breaks.
Less suited forA single Blender with two or three add-ons — Blender's own Import previous settings may be enough. macOS and Linux are not supported yet.
2Getting started

Installation

Requirements

  • Windows 10 or 11, 64-bit
  • Microsoft Edge WebView2 Runtime — built into Windows 11 and usually present on Windows 10
  • One or more Blender versions installed. Tested with 4.1 – 5.3; 2.8x – 4.0 should work but are untested.
  • Internet only for extensions.blender.org downloads and the optional AI assistant

Installer

Run AddonVisor-Setup-0.3.3.exe. No administrator rights are needed. AddonVisor appears in the Start menu and in Settings → Apps, from where you can uninstall it.

Portable

Unzip AddonVisor-0.3.3-portable.zip anywhere and run AddonVisor.exe. The zip also contains the full source code.

Windows SmartScreen may say “Windows protected your PC” the first time, because the app is new and not code-signed yet. Click More info → Run anyway. You only need to do this once.

First start

  1. AddonVisor scans your PC by itself: Program Files, Steam, the Windows registry and portable Blender folders. Each Blender is started invisibly in the background to read its add-ons — this takes a few seconds.
  2. You see the matrix. The newest Blender is selected as the target.
  3. Change the language with the button in the top-right corner: English, Français, Español, Deutsch, Русский, 简体中文, 日本語, Português (Brasil), Română. The Help button opens this guide.

Reading the matrix

SymbolMeaning
✓enabled and working in that Blender version
○installed but switched off
✕enabled but fails to load — hover to see the error
!GPU add-on: cannot load in the background, retested with a small window

The Newest copy column shows the newest version of the add-on found on your PC and which Blender it comes from. Notes under the name tell you when a newer version is on extensions.blender.org, when a version is known to fail, or when you have a patched copy.

3Workflow

1 · Choose the target

Click a column header to make that Blender the target. By default it is the newest one installed — even if you have never opened it.

2 · Tick the add-ons

  • Click an empty cell in the target column to queue that add-on; click again to remove it.
  • Press and drag down the column to tick several at once.
  • Or a shortcut: My 5.1 + 5.2 setup → 5.3 (everything enabled in your two most recent versions), Everything that works → 5.3, or Clear.
  • Add-ons you installed but never enabled are hidden under Show N add-ons that were never enabled.

Which copy is used

You never pick a source version. For each add-on AddonVisor looks at every copy on your PC and, in this order, uses:

  1. your patched copy, if you fixed the add-on (see Fix on a copy);
  2. a newer compatible version from extensions.blender.org — when it exists, or when your local copy is known to fail. The row says “↑ 11.0.12 on extensions.blender.org · will be used” and Blender downloads it itself;
  3. otherwise the newest local copy that declares support for the target (blender_version_min/max or bl_info["blender"]).

3 · Install & test

Press Install & test (N).

  1. Sandbox test. The target's user folder is copied to a temporary folder and Blender is started pointing at that copy. The add-ons are copied in and enabled one by one. Nothing in your real Blender folders changes. GPU add-ons are retested with a small window — you may see it flash.
  2. Results. You see what works and what fails, with the real Python error. Then choose Install the N that work, Fix next to a failing add-on, or Cancel.

Undo & backups

Before a real install AddonVisor saves your preferences and every file it replaces.

  • In the results window: ↶ Undo.
  • Later: ↶ Undo last install in the Target version card.

Undo removes what was added, puts back what was replaced and restores your preferences (or removes them, if that Blender had none before).

4Fixing add-ons

Fix on a copy

When an add-on fails, press Fix next to it. AddonVisor makes a patched copy and applies your fix there — the original is never edited.

You give itWhat happens
A diff (.diff, .patch)Matched by the surrounding code; line numbers are ignored, so AI-written diffs work
A whole AI chat answer (.md or pasted text)Every ```diff block in it is applied
A whole .py fileReplaces the file with the same name inside the add-on
A .zip of the fixed add-onReplaces the whole copy

Drop a file on the box, click it to choose one, or paste text and press Apply pasted text. Patches from any AI work — Claude, ChatGPT, Gemini, Copilot. Then press ↻ Retest in sandbox. If the built-in assistant answered with a diff, Apply the AI's patches and retest does it in one click.

Safety rules

  • All or nothing. If part of a patch does not match, nothing is written and you are told which file and line.
  • No double patches. A patch that is already applied is refused.
  • Indentation matters. In Python it changes the meaning, so it must match (tabs vs 4 spaces is tolerated).
A patch stays on your computer. For paid add-ons an update from the author is usually the safer route — send them the report from %LOCALAPPDATA%\AddonVisor\logs\.

The patch list

Rows with patches show ▸. Click it to see every patch: number, file name, which files it changed and when.

  • ✕ Remove undoes one patch: the copy is rebuilt from the original and the other patches are applied again, in order. If a later patch depends on it, nothing changes and you are told which one to remove first.
  • ↺ Reset all patches — or the small ↺ next to the note — deletes the patched copy; the original is used again.

Example: BlenderGIS in Blender 5.3

Blender 5.3 ships Python 3.13, which removed the imghdr module. BlenderGIS 2.2.10 uses it in two files and fails with ModuleNotFoundError: No module named 'imghdr'. This patch keeps using imghdr where it exists and falls back to a small header check otherwise:

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

Download the complete patch: BlenderGIS_2.2.10_python313_imghdr.diff — then Fix → drop the file → Retest.

5AI assistant

Connect & use

Optional. After a failed test it reads the error report and explains what broke and how to fix it, usually with a ready diff. Without it AddonVisor works fully and nothing leaves your computer.

Gemini — free key with your Google account

  1. Press Continue with Google; Google AI Studio opens in your browser.
  2. Sign in, press Create API key, copy it.
  3. Paste it into AddonVisor and press Connect.

Claude — paid API key

  1. Press Get a Claude API key; the Claude Console opens.
  2. Add credit under Billing, create a key under API keys (shown only once).
  3. Paste it and press Connect. A Claude Pro/Max subscription does not include API use; an analysis costs a few cents.

Using it

  • Read the log automatically after each test (on by default): the answer appears in the results window.
  • Or press Ask AI about these errors.
  • If a model is busy, AddonVisor waits and tries another one by itself; if it still fails, press ↻ Retry.

What is sent to the AI

Only the report of the failed add-ons: the Python error and about 17 lines of code around the failing line. Paths containing your Windows user name are replaced with %USERPROFILE%. Keys are stored encrypted for your Windows user (DPAPI); Disconnect deletes them. Models: Claude claude-opus-5-5; Gemini — the newest Flash model your key can use.

Files & folders

Everything lives in %LOCALAPPDATA%\AddonVisor\ and is kept when you uninstall, so your backups survive.

Folder / fileContents
backups\backup before every real install (used by Undo)
logs\run_*.log and ai_report_*.md for every test
patched\your fixed copies of add-ons, with every patch you applied
settings.jsonlanguage, AI options, extra Blender folders
keys.jsonAI keys, encrypted for your Windows user

Privacy

  • No account, no telemetry, no analytics.
  • Network only for extensions.blender.org (which extensions exist, and downloads through Blender) and the AI provider you connected.
  • Everything else stays on your PC.

Troubleshooting

ProblemWhat to do
A Blender version is missingAdd its folder to settings.json: {"extra_dirs": ["D:\\Apps\\blender-5.3"]}, then Rescan. Microsoft Store installs are not supported.
A Blender window flashes during the testNormal: GPU add-ons are retested with a window. It closes by itself.
“Could not reach the AI: … high demand”The provider is overloaded; other models were already tried. Press ↻ Retry later.
“hunk N does not match the file”The patch was written for different code (another version, or the copy is already patched). Open ▸, remove or reset patches and try again.
“this patch is already applied”Nothing to do — the change is already in the copy.
“could not delete … a file is in use”Close Explorer windows or editors showing files in patched\, then retry.
The window is blankInstall or repair the Microsoft Edge WebView2 Runtime.
SmartScreen / antivirus warningMore info → Run anyway; restore from quarantine if needed — and tell us so we can report the false positive.

To report a problem, attach the newest run_*.log from %LOCALAPPDATA%\AddonVisor\logs\ and list your Blender versions: GitHub issues or gmcis.cutvisor@gmail.com.

FAQ

Is this a Blender add-on?

No — a separate Windows app. That is why it can see all your Blender versions at once.

Can it break my Blender setup?

Everything is tested in a sandbox first; real installs need your confirmation, take a backup and can be undone.

Does it fix add-ons automatically?

It uses a newer compatible version from extensions.blender.org when there is one; otherwise you apply a patch (from the built-in AI or any other) to a copy and retest. Some add-ons need their author.

Does it work with add-ons I bought?

Yes — it copies what is installed on your PC and never shares your add-ons.

Mac / Linux?

Not yet.

Is the source code included?

Yes. AddonVisor is licensed under the GNU GPL v3; the source is in the download.
