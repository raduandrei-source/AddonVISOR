AddonVisor

Benutzerhandbuch · Version 0.3.3 · Windows 10/11 · getestet mit Blender 4.1 – 5.3
1Überblick

Was es ist

Eine neue Blender-Version erscheint, Sie installieren sie — und Ihre Add-ons fehlen. Sie kopieren sie einzeln hinüber, aktivieren sie und merken erst dann, welche kaputt sind, wenn Sie sie brauchen.

AddonVisor ist eine kleine Windows-App, die das für Sie erledigt, und zwar außerhalb von Blender. Sie findet jedes Blender auf Ihrem PC, zeigt, welche Add-ons Sie in welcher Version nutzen, überträgt sie in die gewünschte Version, testet sie in einer Sandbox, bevor sich etwas ändert, und sagt Ihnen genau, was kaputtgegangen ist und warum — samt Lösung, wenn es eine gibt.

Philosophie

Außerhalb von Blender – deshalb sieht AddonVisor alles

Ein Add-on in Blender sieht nur diese eine Version. AddonVisor läuft eigenständig und kann so alle Ihre Blender-Versionen gleichzeitig vergleichen — auch solche, die Sie nie geöffnet haben.

Erst testen, dann ändern

Nichts wird wirklich installiert, bevor es in einer Wegwerfkopie der Einstellungen der Zielversion funktioniert hat. Sie entscheiden erst nach dem Ergebnis, was installiert wird.

Originale bleiben unangetastet

Ältere Blender-Versionen werden nur gelesen. Reparaturen erfolgen auf einer Kopie. Jede echte Installation wird gesichert und lässt sich rückgängig machen.

Wenige Klicks

AddonVisor scannt von selbst und wählt das neueste Blender als Ziel sowie die neueste Kopie jedes Add-ons. Die meisten Migrationen brauchen zwei Klicks: eine Abkürzung, dann Installieren & testen.

Für wen

Gut geeignetFür alle mit mehreren Blender-Versionen und mehr als einer Handvoll Add-ons; Studios, die ein Team auf ein neues Release umstellen; Add-on-Entwickler, die sehen wollen, wo ihr Add-on bricht.
Weniger geeignetEin einzelnes Blender mit zwei, drei Add-ons — hier genügt vielleicht Blenders eigenes Import previous settings. macOS und Linux werden noch nicht unterstützt.
2Erste Schritte

Installation

Voraussetzungen

  • Windows 10 oder 11, 64 Bit
  • Microsoft Edge WebView2 Runtime — in Windows 11 integriert und unter Windows 10 meist vorhanden
  • Eine oder mehrere installierte Blender-Versionen. Getestet mit 4.1 – 5.3; 2.8x – 4.0 sollten funktionieren, sind aber ungetestet.
  • Internet nur für Downloads von extensions.blender.org und den optionalen KI-Assistenten

Installationsprogramm

Starten Sie AddonVisor-Setup-0.3.3.exe. Administratorrechte sind nicht nötig. AddonVisor erscheint im Startmenü und unter Einstellungen → Apps, wo Sie es deinstallieren können.

Portable Version

Entpacken Sie AddonVisor-0.3.3-portable.zip an einen beliebigen Ort und starten Sie AddonVisor.exe. Das ZIP enthält auch den vollständigen Quellcode.

Windows SmartScreen meldet beim ersten Start eventuell „Der Computer wurde durch Windows geschützt“, weil die App neu und noch nicht codesigniert ist. Klicken Sie auf Weitere Informationen → Trotzdem ausführen. Das ist nur einmal nötig.

Erster Start

  1. AddonVisor durchsucht Ihren PC von selbst: Program Files, Steam, die Windows-Registrierung und portable Blender-Ordner. Jedes Blender wird unsichtbar im Hintergrund gestartet, um seine Add-ons auszulesen — das dauert ein paar Sekunden.
  2. Sie sehen die Matrix. Das neueste Blender ist als Ziel ausgewählt.
  3. Die Sprache ändern Sie mit der Schaltfläche oben rechts: English, Français, Español, Deutsch, Русский, 简体中文, 日本語, Português (Brasil), Română. Die Schaltfläche Hilfe öffnet dieses Handbuch.

Die Matrix lesen

SymbolBedeutung
✓in dieser Blender-Version aktiv und funktionsfähig
○installiert, aber ausgeschaltet
✕aktiv, lädt aber nicht — Mauszeiger darüber halten, um den Fehler zu sehen

Die Spalte Neueste Kopie zeigt die neueste Version des Add-ons auf Ihrem PC und aus welchem Blender sie stammt. Hinweise unter dem Namen zeigen an, wenn es auf extensions.blender.org eine neuere Version gibt, wenn eine Version bekanntermaßen fehlschlägt oder wenn Sie eine gepatchte Kopie haben.

3Arbeitsablauf

1 · Ziel wählen

Klicken Sie auf einen Spaltenkopf, um dieses Blender zum Ziel zu machen. Standardmäßig ist es das neueste installierte — auch wenn Sie es nie geöffnet haben.

2 · Add-ons anhaken

  • Klicken Sie auf eine leere Zelle in der Zielspalte, um das Add-on vorzumerken; ein weiterer Klick entfernt es wieder.
  • Klicken und ziehen Sie die Spalte hinunter, um mehrere auf einmal anzuhaken.
  • Oder eine Abkürzung: Mein 5.1 + 5.2-Setup → 5.3 (alles, was in Ihren beiden neuesten Versionen aktiv ist), Alles, was läuft → 5.3 oder Leeren.
  • Installierte, aber nie aktivierte Add-ons sind unter N nie aktivierte Add-ons zeigen ausgeblendet.

Welche Kopie verwendet wird

Eine Quellversion wählen Sie nie. Für jedes Add-on prüft AddonVisor alle Kopien auf Ihrem PC und verwendet in dieser Reihenfolge:

  1. Ihre gepatchte Kopie, falls Sie das Add-on repariert haben (siehe Auf einer Kopie reparieren);
  2. eine neuere kompatible Version von extensions.blender.org — wenn es sie gibt oder wenn Ihre lokale Kopie bekanntermaßen fehlschlägt. Die Zeile zeigt „↑ 11.0.12 auf extensions.blender.org · wird verwendet“, und Blender lädt sie selbst herunter;
  3. andernfalls die neueste lokale Kopie, die die Zielversion als unterstützt angibt (blender_version_min/max oder bl_info["blender"]).

3 · Installieren & testen

Klicken Sie auf Installieren & testen (N).

  1. Sandbox-Test. Der Benutzerordner der Zielversion wird in einen temporären Ordner kopiert, und Blender wird mit dieser Kopie gestartet. Die Add-ons werden hineinkopiert und einzeln aktiviert. In Ihren echten Blender-Ordnern ändert sich nichts. GPU-Add-ons werden mit einem kleinen Fenster erneut getestet — es kann kurz aufblitzen.
  2. Ergebnisse. Sie sehen, was funktioniert und was fehlschlägt, mit dem echten Python-Fehler. Dann wählen Sie Die N funktionierenden installieren, Reparieren neben einem fehlerhaften Add-on oder Abbrechen.

Rückgängig & Sicherungen

Vor einer echten Installation sichert AddonVisor Ihre Einstellungen und jede Datei, die ersetzt wird.

  • Im Ergebnisfenster: ↶ Rückgängig.
  • Später: ↶ Letzte Installation rückgängig in der Karte Zielversion.

Rückgängig entfernt, was hinzugefügt wurde, stellt Ersetztes wieder her und setzt Ihre Einstellungen zurück (oder entfernt sie, falls dieses Blender vorher keine hatte).

4Add-ons reparieren

Auf einer Kopie reparieren

Wenn ein Add-on fehlschlägt, klicken Sie daneben auf Reparieren. AddonVisor erstellt eine gepatchte Kopie und wendet Ihre Korrektur dort an — das Original wird nie bearbeitet.

Was Sie übergebenWas passiert
Ein Diff (.diff, .patch)Wird anhand des umgebenden Codes zugeordnet; Zeilennummern werden ignoriert, daher funktionieren auch von KI geschriebene Diffs
Eine ganze KI-Chat-Antwort (.md oder eingefügter Text)Jeder ```diff-Block darin wird angewendet
Eine ganze .py-DateiErsetzt die gleichnamige Datei im Add-on
Ein .zip des reparierten Add-onsErsetzt die ganze Kopie

Ziehen Sie eine Datei auf das Feld, klicken Sie darauf, um eine auszuwählen, oder fügen Sie Text ein und klicken Sie auf Eingefügten Text anwenden. Patches von jeder KI funktionieren — Claude, ChatGPT, Gemini, Copilot. Klicken Sie dann auf ↻ In der Sandbox erneut testen. Hat der integrierte Assistent mit einem Diff geantwortet, erledigt KI-Patches anwenden und erneut testen beides mit einem Klick.

Sicherheitsregeln

  • Alles oder nichts. Passt ein Teil eines Patches nicht, wird nichts geschrieben, und Sie erfahren, welche Datei und Zeile betroffen ist.
  • Keine doppelten Patches. Ein bereits angewendeter Patch wird abgelehnt.
  • Einrückung zählt. In Python ändert sie die Bedeutung, daher muss sie übereinstimmen (Tabs statt 4 Leerzeichen werden toleriert).
Ein Patch bleibt auf Ihrem Computer. Bei kostenpflichtigen Add-ons ist ein Update vom Autor meist der sicherere Weg — schicken Sie ihm den Bericht aus %LOCALAPPDATA%\AddonVisor\logs\.

Die Patch-Liste

Zeilen mit Patches zeigen ▸. Klicken Sie darauf, um alle Patches zu sehen: Nummer, Dateiname, welche Dateien geändert wurden und wann.

  • ✕ Entfernen macht einen Patch rückgängig: Die Kopie wird aus dem Original neu aufgebaut, und die übrigen Patches werden der Reihe nach erneut angewendet. Hängt ein späterer Patch davon ab, ändert sich nichts, und Sie erfahren, welchen Sie zuerst entfernen müssen.
  • ↺ Alle Patches zurücksetzen — oder das kleine ↺ neben dem Hinweis — löscht die gepatchte Kopie; danach wird wieder das Original verwendet.

Beispiel: BlenderGIS in Blender 5.3

Blender 5.3 bringt Python 3.13 mit, in dem das Modul imghdr entfernt wurde. BlenderGIS 2.2.10 nutzt es in zwei Dateien und schlägt mit ModuleNotFoundError: No module named 'imghdr' fehl. Dieser Patch verwendet imghdr weiter, wo es vorhanden ist, und greift sonst auf eine kleine Header-Prüfung zurück:

--- a/core/georaster/img_utils.py
+++ b/core/georaster/img_utils.py
@@ -23,3 +23,19 @@
 import struct
-import imghdr
+try:
+	import imghdr
+except ImportError:  # removed in Python 3.13 (Blender 5.3+)
+	class imghdr:
+		@staticmethod
+		def what(_file, h): ...

Den vollständigen Patch herunterladen: BlenderGIS_2.2.10_python313_imghdr.diff — dann Reparieren → Datei ablegen → In der Sandbox erneut testen.

5KI-Assistent

Verbinden & nutzen

Optional. Nach einem fehlgeschlagenen Test liest der KI-Assistent den Fehlerbericht und erklärt, was kaputt ist und wie es sich beheben lässt, meist mit einem fertigen Diff. Ohne ihn funktioniert AddonVisor vollständig, und nichts verlässt Ihren Computer.

Gemini — kostenloser Schlüssel mit Ihrem Google-Konto

  1. Klicken Sie auf Weiter mit Google; Google AI Studio öffnet sich in Ihrem Browser.
  2. Melden Sie sich an, klicken Sie auf Create API key und kopieren Sie den Schlüssel.
  3. Fügen Sie ihn in AddonVisor ein und klicken Sie auf Verbinden.

Claude — kostenpflichtiger API-Schlüssel

  1. Klicken Sie auf Claude-API-Schlüssel holen; die Claude Console öffnet sich.
  2. Laden Sie unter Billing Guthaben auf und erstellen Sie unter API keys einen Schlüssel (wird nur einmal angezeigt).
  3. Fügen Sie ihn ein und klicken Sie auf Verbinden. Ein Claude-Pro/Max-Abo enthält keine API-Nutzung; eine Analyse kostet ein paar Cent.

Nutzung

  • Protokoll nach jedem Test automatisch lesen (standardmäßig an): Die Antwort erscheint im Ergebnisfenster.
  • Oder klicken Sie auf KI zu diesen Fehlern fragen.
  • Ist ein Modell ausgelastet, wartet AddonVisor und probiert selbstständig ein anderes; schlägt es trotzdem fehl, klicken Sie auf ↻ Erneut versuchen.

Was an die KI gesendet wird

Nur der Bericht über die fehlgeschlagenen Add-ons: der Python-Fehler und etwa 17 Codezeilen rund um die fehlerhafte Zeile. Pfade mit Ihrem Windows-Benutzernamen werden durch %USERPROFILE% ersetzt. Schlüssel werden für Ihren Windows-Benutzer verschlüsselt gespeichert (DPAPI); Trennen löscht sie. Modelle: Claude claude-opus-5-5; Gemini — das neueste Flash-Modell, das Ihr Schlüssel nutzen kann.

FAQ

Ist das ein Blender-Add-on?

Nein — eine eigenständige Windows-App. Deshalb sieht sie alle Ihre Blender-Versionen gleichzeitig.

Kann AddonVisor meine Blender-Einrichtung beschädigen?

Alles wird zuerst in einer Sandbox getestet; echte Installationen brauchen Ihre Bestätigung, legen eine Sicherung an und lassen sich rückgängig machen.

Repariert AddonVisor Add-ons automatisch?

Es verwendet eine neuere kompatible Version von extensions.blender.org, wenn es eine gibt; andernfalls wenden Sie einen Patch (von der integrierten KI oder einer anderen) auf eine Kopie an und testen erneut. Manche Add-ons kann nur ihr Autor reparieren.

Funktioniert AddonVisor mit gekauften Add-ons?

Ja — es kopiert, was auf Ihrem PC installiert ist, und gibt Ihre Add-ons nie weiter.

Mac / Linux?

Noch nicht.

Ist der Quellcode enthalten?

Ja. AddonVisor steht unter der GNU GPL v3; der Quellcode ist im Download enthalten.
